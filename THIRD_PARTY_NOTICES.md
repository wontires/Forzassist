# Third-party notices

This project uses the following third-party components:

- PySide6 / Qt for the GUI.
- vgamepad for virtual Xbox 360 controller output.
- ViGEmBus by Nefarius Software Solutions e.U. for the kernel-mode virtual gamepad bus driver.

The installer script downloads ViGEmBus 1.22.0 from the archived official GitHub release and includes it as a prerequisite installer.
Review the licenses of all dependencies before publishing a public release.
